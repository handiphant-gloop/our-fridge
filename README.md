# 🧊 우리집 냉장고

가족이 같은 냉장고를 보면서 식재료의 **수량**과 **유통기한**을 관리하는 모바일 웹 앱(PWA)입니다.
설치 없이 브라우저로 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 주요 기능

- **보관함별 관리**: 냉장실 · 냉동실 · 김치냉장고 · 실온(팬트리) 기본 제공, 설정에서 추가·이름 변경·삭제
- **식재료 카드**: 품목명, 보관함 배지, 수량 ± 버튼, 단위, 유통기한 D-day(만료 빨강 / D-3 이내 주황 / 여유 초록), 메모
- **요약**: 전체 개수, 임박(D-3 이내), 만료 개수 — 눌러서 바로 필터
- **정렬·검색**: 유통기한 임박순 / 최근 등록순 / 이름순, 이름·메모 검색
- **두 가지 등록 방식**
  - 직접 입력: 자주 쓰는 식재료 원터치 칩, 오늘/+3/+7/+14/+30일 빠른 날짜 버튼
  - 영수증 인식: 사진 촬영·업로드 → Gemini(`gemini-2.5-flash` → `gemini-2.0-flash` 자동 재시도)로 품목·수량·보관함·유통기한 추출 → 체크박스 미리보기에서 수정 후 일괄 등록
  - API 키가 없어도 **텍스트 붙여넣기 파싱**과 **Tesseract.js OCR(한국어+영어)** 로 등록 가능
- **장보기 목록**: 다 쓴 재료를 자동으로 담기(수량 0 → 확인), 체크 후 원터치 입고, 체크 항목 일괄 입고
- **가족 공유**: Supabase REST + 8초 폴링으로 두 폰 동기화. 설정이 없으면 이 폰(localStorage)에만 저장
- **오프라인**: 서비스 워커가 앱 화면을 캐시, 마지막 데이터로 열림
- **백업**: JSON 내보내기/가져오기

## 파일 구성

```
fridge-app/
├── index.html          화면 구조 (모바일 퍼스트, 한국어)
├── styles.css          디자인 (라이트/다크 자동)
├── app.js              상태·화면·CRUD·동기화
├── integrations.js     식재료 사전·영수증 파서·Gemini·OCR·Supabase 클라이언트·SQL
├── manifest.json       PWA 매니페스트 (홈 화면 추가)
├── sw.js               서비스 워커 (앱 껍데기 캐시)
├── schema.sql          Supabase 테이블 정의
└── icons/              앱 아이콘 (192/512/maskable/apple-touch)
```

## 바로 실행

로컬에서 확인할 때 (서비스 워커는 `file://` 에서 동작하지 않습니다):

```bash
cd fridge-app
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages에 올리면 `https://<계정>.github.io/<저장소>/` 로 가족이 함께 접속할 수 있습니다.

## 가족 공유 설정 (Supabase, 무료)

1. [supabase.com](https://supabase.com/dashboard) 가입 → **New project** 생성
2. **SQL Editor** → `schema.sql` (앱 설정 화면의 SQL 복사 버튼) 붙여넣고 **RUN**
3. **Project Settings → API** 의 `Project URL` 과 `anon public key` 를 앱 설정에 입력
4. **우리집 공유 코드** 를 만들고(예: `home-a1b2c3`) 두 폰에 똑같이 입력 → **저장하고 연결**

연결하면:
- 서버가 비어 있으면 이 폰의 데이터를 올려 가족 냉장고를 만듭니다.
- 이미 가족 데이터가 있으면 이 폰 데이터와 합칩니다(같은 id는 서버 우선, 겹치지 않는 항목은 추가).
- 이후 8초마다, 그리고 화면으로 돌아올 때 자동으로 맞춥니다. 변경은 즉시 서버로 보내고, 실패하면 큐에 쌓아 두었다가 다시 보냅니다.

> ⚠️ 공유 코드로만 구분하는 간단한 구조입니다. URL과 anon key를 아는 사람은 다른 코드도 읽을 수 있으니, 집 안에서 쓰는 가벼운 용도로만 사용하고 비밀번호 같은 민감한 정보는 넣지 마세요.

## 영수증 인식

- **Gemini 사용**: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 무료 키 발급 → 앱 설정에 저장. 사진은 Google API로만 전송됩니다. 키는 이 기기 localStorage에만 저장돼요.
- **키 없이**: `글자만 추출(OCR)` 은 Tesseract.js CDN을 처음 한 번 내려받아 한국어+영어를 읽습니다(인터넷 필요, 첫 실행 30초 정도). 또는 영수증 텍스트를 붙여넣고 `품목 찾기`.
- 인식 결과는 이름·수량·단위·보관함·유통기한(일)을 고칠 수 있고, 체크한 항목만 등록됩니다.

## 데이터

- 로컬 모드: 브라우저 `localStorage` (`fridge.v1.data`, `fridge.v1.settings`, `fridge.v1.outbox`)
- 설정 → 데이터에서 JSON 백업/복원, 예시 데이터, 전체 삭제
- 가족 공유 중에는 서버 데이터가 우선이며, 가져오기·전체 삭제는 연결 해제 후 사용할 수 있습니다.
