로컬 저장

두 폰에서 같은 냉장고를 보려면 Supabase 무료 프로젝트를 만들고 아래 값을 넣어 주세요. 넣기 전에도 이 폰에 저장되어 바로 쓸 수 있습니다.

처음 연결하는 방법 (3단계)
  1. supabase.com 가입 → New project 만들기 (무료)
  2. 왼쪽 SQL Editor → 아래 SQL 복사해 붙여넣기 → RUN
  3. Project Settings → API에서 Project URL과 anon public key를 복사해 위에 입력 → 공유 코드 만들기 → 저장하고 연결

🧾 영수증 자동 인식

        키 없음
      

      
      

        
        
      

      
키 발급: aistudio.google.com/apikey → Create API key. 키는 이 기기 브라우저(localStorage)에만 저장되고, 영수증 인식 때 Google로만 전송됩니다.

      
키가 없어도 글자 인식(OCR, Tesseract.js)과 텍스트 붙여넣기로 등록할 수 있어요. OCR은 인터넷 연결이 필요하고 첫 실행이 느립니다.
